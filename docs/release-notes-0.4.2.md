한녕 0.4.2는 앞 단어 교정, 입력 지연 개선, 자동 업데이트를 추가한 버전입니다.

## 바뀐 점

- 앞 단어는 조합 영역을 유지하지 않고 확정하며, 뒤 단어로 언어가 분명해지면 이미 입력한 앞부분도 고칩니다. `to go home`·`to go home을` 같은 문구를 Space나 Return에서 교정합니다.
- 빠르게 이어 입력하거나 공백을 지웠다 다시 입력할 때, 커서를 옮기거나 줄을 바꿀 때의 교체·입력 순서를 개선했습니다.
- 평범한 단어 확정마다 입력창 반영을 기다리던 처리를 제거했습니다. 실제 교체할 문구만 검증하고, 삭제 반영 중 확인 오류로 교정이 중단되는 문제를 수정했습니다.
- 반대 언어 미리보기가 이전 단어 앞에 남던 위치 문제를 수정했습니다.
- 설정 → 정보에 업데이트 수동 확인, 자동 확인, 자동 다운로드·설치를 추가했습니다. 다운로드한 자동 업데이트는 한녕이 종료될 때 적용합니다.
- 앞 단어 교정은 기본 기능입니다. 설정 → 정보의 **손쉬운 사용 허용...**에서 권한을 허용해 주세요.
- 키체인 인증창 등 보안 입력 중에는 시스템 ABC로 전환하고, 보안 입력이 끝나면 한녕으로 돌아옵니다. 처음부터 ABC를 사용 중이었다면 그대로 유지합니다. 이 전환은 입력 내용이나 암호를 읽지 않습니다.

## 설치·업데이트

1. `Hannyeong-0.4.2-arm64.pkg`를 내려받아 설치합니다.
2. 메뉴바 입력 메뉴에서 **한녕**을 선택합니다.
3. 입력기가 보이지 않거나 기존 앱에서 변환되지 않으면 작업을 저장하고 로그아웃 후 다시 로그인합니다.

기존 공개 버전(0.4.1 이하)에는 자동 업데이트가 없으므로 이번 pkg를 한 번 설치해야 합니다. 이후에는 설정 → 정보 → 업데이트에서 확인할 수 있습니다. 기존 교정 기록과 개인 보정값은 유지하며, 판별 모델은 0.4.1과 같습니다. 입력 내용과 개인 학습 데이터는 전송하지 않으며, 네트워크는 업데이트 확인과 다운로드에 사용합니다.

## 확인 범위와 남아 있는 제한

- Apple silicon Mac, macOS 15 이상. macOS 27.2에서 확인했습니다.
- 실제 Chrome의 일반·서식 입력창 38회 검사와 기본 입력·앞 단어 교정·오른쪽 Command 회귀 검사를 통과했습니다. Codex에서도 사용자가 자동 변환과 입력 지연 개선을 확인했습니다.
- Sparkle의 업데이트 판별, 서명된 ZIP 다운로드·설치·재실행, 변조된 ZIP 거부를 로컬 테스트 앱에서 확인했습니다.
- 실제 macOS 키체인 인증창에서 수동 전환 없이 암호가 입력되고, 창을 닫으면 한녕으로 복귀하는 것을 확인했습니다.
- 일부 혼합 문장(`한글 쓰다가 to go home 다시 한글`, `내 생각은 to go home이 맞아`, `오늘 기분은 so so 그래도 괜찮아`)의 판별 오류는 남아 있으며, 이번 버전에서 모델 규칙은 바꾸지 않았습니다.
